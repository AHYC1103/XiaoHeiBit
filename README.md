# XiaoHeiBit 小黑币（XiaoHeiBit / XHB）

> 全网首个小黑私有链 · 一个不到 1MB 就能跑起来的完整区块链钱包

---

## 一、什么是区块链（写给第一次接触的人）

区块链本质上就是一本**大家共同维护、谁也改不了的账本**。

你可以把它想象成一页一页钉在一起的账本：

- **区块（Block）**：账本的一页，上面记着一段时间内发生的所有交易（谁转给谁多少钱）。
- **链（Chain）**：每一页都用一个密码学指纹（哈希）指向上一页，一页接一页钉成一串，所以叫"区块链"。
- **为什么改不了**：如果你偷偷改了某一页的内容，这一页的指纹就变了，后面所有页的指纹也会跟着对不上，全网一眼就能发现有人作弊。
- **挖矿（PoW）**：为了决定谁有资格写下一页，大家比赛解一道很难但很容易验证的数学题，解出来的人就能记账并拿到奖励。这就是工作量证明（Proof of Work）。
- **钱包**：本质就是一对钥匙——**私钥**（你自己保管，用来签字花钱）和**地址**（公开给别人收款）。谁掌握私钥，谁就拥有这笔钱。

小黑币就是把这套原理，用最少的代码、最轻的依赖，完完整整实现了一遍。

## 二、币种介绍：XHB（小黑币）

- **币种符号**：XHB / XiaoHeiBit
- **类型**：本地私有链（你自己的手机就是一台全节点）
- **初始供给**：创世块发行，总量固定
- **出块奖励**：当前每个块奖励 **10 XHB**（可在 `config.json` 的 `miner_reward` 调整，调高=通胀，调低=更稀缺）
- **挖矿难度**：当前 **5**（`difficulty`，越大越难挖、越稀缺）
- **交易手续费**：每笔 **1 XHB**（`tx_fee`）
- **发行方式**：纯挖矿产出，没有预挖、没有 ICO、没有老板钱包
- **定位**：一个人就能跑、能随便折腾、用来学习和把玩的"玩具级但五脏俱全"的链

它不是要和比特币以太坊竞争，而是把"一条链到底是怎么转起来的"这件事，压缩到你能一眼看完、亲手改两行参数的程度。

## 三、设计启发

这个项目最初的动机很简单：**想自己写一条能跑的链，而不是只在书里看原理。**

几个关键取舍：

1. **小就是美德**。核心代码不到 1MB，纯 Python 标准库 + Flask + SQLite。没有重型框架、没有数据库集群、没有 P2P 网络的复杂度——一台手机、一个文件、一个进程就是一条完整的链。
2. **钱包和签名放在服务端**。早期为了快速跑通，钱包私钥和签名都在后端，APP 只负责 UI 和调接口。这是玩具链的取舍，正式公链应该把私钥留在用户本地。
3. **NFT 用一次性码**。转账 NFT 时生成一个用一次就失效的随机码，对方扫码/输码才能接收，避免"扫错人就把 NFT 送出去"。
4. **安卓端纯原生、不套壳**。不用 WebView，全部用 Kotlin 手写 View，APK 压到 400KB 出头，扫码、壁纸、深浅主题都是自己画的。
5. **配置即文档**。`config.json` 顶部直接写 `_注释`，改参数不用翻文档。

## 四、功能清单

### 钱包
- 助记词 / 随机私钥两种方式创建钱包
- 导入（私钥 / 助记词）、导出、切换、重命名、换图标
- 多钱包管理，当前钱包高亮

### 转账与挖矿
- 地址转账（16 位 hex 地址），交易带签名和 nonce
- 交易自动进 mempool，后台自动挖一个块打包
- 手动挖矿（一次挖 N 块），奖励给当前钱包
- 链完整性校验、余额查询、交易历史分页

### NFT
- 铸造：名称 + 图片 IPFS CID + 发行量 + 描述
- 接收：一次性随机码（用完即失效），扫码自动识别
- 直转：直接填对方地址转账
- 图片通过公开 IPFS 网关预览

### 安卓 APP
- 纯原生 Kotlin，无 WebView
- 扫码收发（手写二维码生成 + 解码）
- 币种详情页、NFT 钱包、壁纸主题
- 主链/测试网切换预留

## 五、技术架构

```
┌─────────────┐   HTTP/JSON   ┌──────────────────┐
│  安卓 APP    │ ────────────▶ │  Flask (main.py)  │
│ (纯原生Kotlin)│ ◀──────────── │  core/api.py      │
└─────────────┘               └────────┬─────────┘
                                        │
                    ┌───────────────────┼───────────────┐
                    ▼                   ▼               ▼
              blockchain.py        wallet.py        nft.py
              出块/哈希/难度        密钥/签名          NFT
                    │                   │               │
                    └───────── SQLite (chain.db) ────────┘
```

- **后端**：Python 3 + Flask + SQLite，单进程多线程
- **核心**：`core/` 下五个文件，各司其职
- **前端**：`webui/` 网页版（APP 走 `/api/` 不依赖它）
- **APP**：Kotlin + Android framework，minSdk 26 / target 34，arm64

## 七、安装与运行

```bash
cd xiaoheibit
bash start.sh
# [OK] XiaoHeiBit 主链 http://127.0.0.1:8222
```

停止：`kill $(cat tmp/run.pid)`，或直接再跑一次 `start.sh`（会自动先停旧进程）。

配置项（`config.json`）：

| 字段 | 含义 | 当前值 |
|---|---|---|
| webui_port | 监听端口 | 8222 |
| difficulty | 挖矿难度 | 5 |
| miner_reward | 出块奖励 | 10 |
| auto_mine | 自动挖矿 | true |
| tx_fee | 交易手续费 | 1 |

改完重启即生效。
